# hmbakhsh Homebrew Tap

Homebrew packages maintained by [hmbakhsh](https://github.com/hmbakhsh).

## Browser Router

Install the macOS app and CLI:

```sh
brew install --cask hmbakhsh/tap/browser-router
```

Then configure it:

```sh
browser-router setup
browser-router config
browser-router validate
browser-router default
```

See [rootie.hbak.co](https://rootie.hbak.co) or the
[source repository](https://github.com/hmbakhsh/browser-router).
